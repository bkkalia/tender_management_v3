Tender Management Utility v3.0

Overview:
Desktop application to load, search, filter, visualize, merge and manage tender data with calendar & task integration.

Key Features:
- Multi-folder data load (Excel / CSV)
- Live search (department + global, AND/OR logic)
- Date presets and custom ranges
- Dashboard KPIs
- Saved search profiles
- Calendar integration
- Data visualization
- Export functionality
- Settings-driven configuration

Building Executable:
Run: python build_exe.py

Requirements:
- Python with required packages
- PyInstaller for building

For more details, see README.md and HELP.md in the application folder.

Support:
Ensure required packages are installed: pandas, tkcalendar, openpyxl, matplotlib
