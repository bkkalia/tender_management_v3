Key Features v3.2

Multi-Source Data Loading

Load tender data from multiple Excel/CSV files with intelligent merging, deduplication, and change detection across data sources.

Advanced Search & Filtering

Global search with AND/OR logic, department filters, date range presets, and live search with debounced performance optimization.

Data Visualization

Interactive charts showing department distribution, monthly trends, and KPI dashboards with matplotlib integration.

Calendar Integration

Add critical tenders to calendar with notes, reminders, and task management. Supports iCal export and multi-row operations.

Performance Monitoring

Real-time CPU, memory, and disk usage tracking with comprehensive benchmarking suite and performance dashboards.

Saved Searches & Profiles

Save and load filter combinations, column configurations, and search profiles for quick access to frequently used views.

Export & Reporting

Export filtered data to Excel/CSV with current column order and visibility. Generate performance reports and analytics.

Settings Management

Configurable data folders, merge keys, critical fields, backup settings, and UI preferences with live propagation.

CLI & Automation

Command-line interface for batch processing, automated workflows, and system integration capabilities.
