Key Features

📊

Advanced Data Processing

Multi-folder data loading from Excel/CSV files with intelligent merging, deduplication, and data cleaning for reliable tender data management.

🔍

Smart Search & Filtering

Live search with department and global filters, date presets (Live, Today, Next 3/7/30 Days), and custom range selection with AND/OR logic.

📈

Real-time Dashboard

Dynamic KPIs showing live/expired tenders, due windows, department distribution, and filtered results with instant updates.

💾

Saved Search Profiles

Save and load search configurations for frequently used filters, with export/import functionality for sharing profiles.

📅

Calendar Integration

Add tender deadlines to calendar applications with notes, supporting single or multiple row selections for efficient task management.

📊

Data Visualization

Interactive charts showing department distribution and monthly tender trends, with export capabilities for reporting.

⚙️

Column Configuration

Reorder, hide/show, and resize columns with persistent settings, plus sortable headers with chronological and numeric sorting.

🚀

High Performance

Debounced asynchronous filtering for large datasets (50K+ rows), multi-threaded processing, and optimized memory usage.

📊

Performance Monitoring

Real-time system performance tracking with live CPU, memory, and disk usage metrics. Integrated status bar shows RAM usage, data records, and last operation tracking with automatic updates every 2 seconds.

🧪

Advanced Testing Suite

Comprehensive GUI-based performance testing with advanced dummy data generator (50K+ records), automated import/testing workflows, and professional markdown reports with system specifications and optimization recommendations.

🔍

Advanced Search Architecture

In-memory inverted token indexing for large datasets (5K+ rows) with set intersection operations for AND/OR logic in global search, automatic fallback to DataFrame scanning for smaller datasets.

⚡

Optimized Performance

Debounced asynchronous filtering (250ms delay) for large datasets, multi-threaded processing, cached lowercased columns for case-insensitive search, and precompiled regex patterns for improved responsiveness.
